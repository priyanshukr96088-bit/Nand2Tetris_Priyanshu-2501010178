## Directory Contents
- `CPU.hdl`: Complete Hack CPU hardware implementation.
- `Memory.hdl`: Hack Memory chip routing RAM16K, Screen, and Keyboard.
- `Computer.hdl`: Top-level Hack Computer chip connecting CPU, Memory, and ROM32K.
- `emulator.html`: Interactive browser-based visualization of the Box program.
- `assembler.py`: Python assembler with two-pass symbol resolution and duplicate-label warning feature.
- `run_test.py`: Checks the Box program's key-press, drawing, and key-release behavior.
- `Box.asm`: Hack assembly program drawing a 48x20 pixel black box at Row 178 on keypress, clearing on release.
- `Box.hack`: Assembled binary machine code generated by `assembler.py`.
- `symbols.txt`: Exported symbol table.
- `REPORT.md`: Project report documenting implementation and verified test results.
- `VIVA_PREP.md`: Rapid-fire viva questions and explanations of on-the-spot code changes.
- `screenshot_box.png`: Generated visualization of the expected Box program output.
- `screenshot_tests.png`: Generated summary of the five passing official hardware tests.

## How to Run the Assembler
To assemble `Box.asm` into `Box.hack`:
```bash
python assembler.py Box.asm
```

To test on other programs:
```bash
python assembler.py Add.asm
python assembler.py Max.asm
```

To run the Box program checks:
```bash
python run_test.py
```

## Run the Hardware Simulator tests
Open the Nand2Tetris `HardwareSimulator.bat`, load each `.tst` script, and run it. Before running `Memory.tst`, set **View** to **Screen**. When prompted, click the Keyboard icon and hold uppercase `K` until the script continues. Confirm the final comparison succeeds.

## How to Run in CPU Emulator
1. Open the Nand to Tetris `CPUEmulator.bat`.
2. Load Program: select `Box.hack`.
3. Set Animation to `Program & Data` or `No display` (Fast).
4. Click `Run`.
5. Focus the emulator and hold down any keyboard key -> solid black box appears at Row 178.
6. Release the key -> the box clears immediately back to white.
